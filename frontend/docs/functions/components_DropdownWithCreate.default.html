      Dropdown with an appended "create new" action row.

      Wraps Dropdown and, when onCreateNew is provided, injects a synthetic option with the sentinel value '__CREATE_NEW__' at the end of the list. Selecting that row invokes onCreateNew() and does not call onChange, so the current selection is preserved while the caller opens a modal / prompt.

      All Dropdown props are accepted and forwarded.
