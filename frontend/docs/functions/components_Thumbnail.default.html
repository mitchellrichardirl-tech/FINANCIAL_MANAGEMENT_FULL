      Thumbnail preview for a receipt file served by the backend.

      Lifecycle per src:

      1. HEAD src to read Content-Type without downloading the body. Non-OK responses are run through parseApiError so the displayed message is user-friendly (e.g. "Image no longer available" for 404s).
      2. On success, renders:
        • image/* → <img> bounded by maxHeight.
        • application/pdf → page 1 via react-pdf, rasterized to maxHeight pixels, with text/annotation layers disabled for a lightweight render.
      3. A "Loading…" placeholder overlays the slot until the actual image/PDF finishes loading.

      Parameters

      • props: { src: string | null; alt?: string; maxWidth?: string; maxHeight?: string }
        • src: string | null

          URL of the file to preview. When falsy, the component renders nothing.

        • Optionalalt?: string

          alt text for image previews (ignored for PDFs).

        • OptionalmaxWidth?: string

        • OptionalmaxHeight?: string

          CSS max-height for images and, parsed to an integer, the rasterization height passed to react-pdf's <Page>.

      Returns any
