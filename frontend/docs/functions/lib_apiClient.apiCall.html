    Function apiCall

    • apiCall(
          endpoint: string,
          options?: { method?: string; body?: any; headers?: {}; rest?: any },
      ): Promise<any>

      Perform an HTTP request against the backend API.

      Behavior:

      • If body is a FormData instance it is sent as-is and no Content-Type header is set (the browser adds the multipart boundary).
      • Otherwise, if body is defined, it is JSON.stringify'd and a Content-Type: application/json header is added (caller headers win on merge).
      • Network failures (fetch rejects) are wrapped in AppError.
      • Non-OK HTTP responses are parsed with parseApiError, enriched with a user-facing message, and thrown as ApiError.

      Parameters

      • endpoint: string

        Path relative to API_BASE_URL, e.g. '/transactions'.

      • Optionaloptions: { method?: string; body?: any; headers?: {}; rest?: any } = {}

        Request options.

        • Optionalmethod?: string

          HTTP method.

        • Optionalbody?: any

          Request body. FormData is passed through; anything else is JSON-encoded.

        • Optionalheaders?: {}

          Extra headers to merge into the request.

        • Optionalrest?: any

          Any additional fetch init options (e.g. signal, credentials).

      Returns Promise<any>

      The parsed JSON response body.

      Async

      Throws

      If the network request itself fails (no response).

      Throws

      If the server responds with a non-2xx status.

      Example

      // GET
      const txns = await apiCall('/transactions?limit=50');

      Example

      // POST JSON
      const created = await apiCall('/categories', {
        method: 'POST',
        body: { name: 'Groceries' },
      });

      Example

      // File upload
      const form = new FormData();
      form.append('file', file);
      await apiCall('/receipts/upload', { method: 'POST', body: form });
